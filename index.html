5. Desafio — Sistema de Alunos

O sistema utiliza duas notas para calcular automaticamente a média e determinar a situação do aluno.

ID Nome Curso Turma Nota 1 Nota 2 Média Situação

Fórmula da média

=MÉDIA([@Nota1];[@Nota2])

Fórmula da situação

=SE([@Média]>=7;"Aprovado";"Recuperação")

6. Conexão com SQL

A lógica utilizada no Excel é semelhante à utilizada em bancos de dados SQL.

Excel

=FILTRAR(tbAlunos;tbAlunos[Curso]="Informática")

SQL

SELECT *
FROM alunos
WHERE curso = 'Informática';

7. Perguntas Avaliativas

1. O que é um banco de dados?

É uma coleção organizada de informações que permite armazenar, consultar, alterar e analisar dados.

2. O que é um campo?

É uma coluna que representa um tipo de informação.

3. O que é um registro?

É uma linha completa contendo informações.

4. Para que serve um ID?

Para identificar de forma única cada registro.

5. Qual a diferença entre filtro e classificação?

O filtro seleciona os registros exibidos. A classificação modifica a ordem dos registros.

6. Para que serve a validação de dados?

Para controlar os valores inseridos e manter os dados padronizados.

7. Para que serve a função CONT.SE?

Para contar células que atendem a determinado critério.

8. Para que serve a função MÉDIA?

Para calcular a média dos valores.

9. O que é uma Tabela Dinâmica?

É uma ferramenta utilizada para resumir e analisar dados.

10. Por que manter os dados padronizados?

Para evitar inconsistências e facilitar consultas e análises.
